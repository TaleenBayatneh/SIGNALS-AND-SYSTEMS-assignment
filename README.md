# Signals and Systems – MATLAB Assignment  

## 📌 Overview  
This repository contains my solutions for the **ENEE2312: Signals and Systems** course assignment.  
All tasks are solved using **MATLAB** and cover important concepts from the course, including signals, periodicity, and system responses.  

## 📂 Contents  
- **Q1:** Signal definition and plotting in MATLAB  
- **Q2:** Periodicity and frequency analysis of sinusoidal signals  
- **Q3:** Symbolic solution of given signal equations  
- **Q4:** Step and impulse response of a system (MATLAB + Simulink)  
- **Q5:** Signal operations and visualization  
- **Q6:** Block diagram representation of a system  
- **Q7:** Advanced plotting and verification of results  

## 🛠️ Requirements  
- MATLAB (R2023a or newer recommended)  
- Symbolic Math Toolbox  
- Simulink (for system models)
